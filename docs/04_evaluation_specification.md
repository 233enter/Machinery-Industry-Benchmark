# 评测规范

## 1. 文档目的

本文件用于记录评测对象、评测流程、评分规则、结果解释和报告要求。当前版本只建立规范结构，不预先指定具体指标、协议、基线或阈值。

## 2. 评测目标与范围

评测目标、适用对象、覆盖范围和限制条件待确认。

## 3. 评测任务与输入输出

评测任务定义、输入输出约定和运行条件待确认。

## 4. 评分与结果汇总

评分方法、结果汇总方式、统计处理和可比性要求待确认。

## 5. 评测流程与复现要求

评测步骤、环境要求、随机性处理、日志和复现要求待确认。

## 6. 基线与对比方案

基线范围、对比方案和报告方式待确认。

## 7. 结果报告与质量审查

报告内容、审查流程、异常结果处理和发布规则待确认。

评测规范相关问题和决策记录待补充。
